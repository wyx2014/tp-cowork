# 技能迭代

从用户真实请求提取输入、预期行为和交付物，选取能暴露错误的代表样例。先运行基线，再运行技能指导后的流程；比较产物质量、步骤和失败处理，记录输入与实际结果，不预写结论。检查 description 是否能准确触发目标场景，保留相邻不适用场景用于比较。与用户评审后修改并重跑受影响样例。

GUI 来源中的有用指令已合并：先理解任务、构造真实案例、比较基线与技能、评审产物、迭代说明及 description。GUI 原目录只有 SKILL.md；不提供缺失的 grader/comparator/analyzer agents、eval-viewer 或 schemas，不承诺自动评分。新增评测器须有独立实现和验证。
