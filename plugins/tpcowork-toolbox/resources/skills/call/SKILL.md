使用原生 `call` 工具：拨号时 action 为 dial，用户给了号码就传 number，只给了姓名就传 name（由本机分机表查分机号）；挂断时 action 为 hangup。仅在用户明确要求拨号或挂断时执行。姓名在分机表中唯一匹配时直接拨打，无需让用户再说分机号或重复确认；重名、查不到或没有有效分机号时，把工具返回的提示转告用户，请其提供完整姓名或号码，不要自行猜测或换人。

首次使用：打开“工具箱 → 技能 → call → 设置电话”，填写并确认自己的四位办公分机号。软件从本机分机表（`内部分机信息表.md`）匹配话机地址，可复用旧版 `skills/call/config.json` 中同一主叫的配置。没有旧版凭证时，在设置电话页面首次填写话机登录账号和密码；无法匹配地址时，在“话机与分机表设置”中补充。自己的分机号（主叫）与要拨打的号码是两个不同字段，不得替用户猜测主叫。

配置保存在本机，凭证由 DSH credentials 保存和解析；不要让用户在聊天发送密码，也不要读取、打印或复制个人通讯录和凭证。配置检查和保存不会拨号。返回“已发送指令”只表示话机接受了指令，是否接通以话机状态为准。不得为连通性测试自动拨号，不得通过脚本或 curl 重拨。
