name: call
description: 用户明确要求拨打办公电话或挂断时，使用已选的 Cisco 或 Yealink 话机。Cisco 支持按姓名、邮箱或完整 IP 分机号拨打。Yealink 支持按姓名或号码拨打，也支持挂断。
---

选择 Yealink 时，在聊天里发送“给张三打电话”“拨打 3737”“挂断电话”或 `/call 姓名或号码`，软件会直接处理整句明确指令并显示话机返回结果。

用原生 `call` 工具。拨号用 `action: dial`，将用户提供的号码传给 `number`，姓名或邮箱传给 `name`。挂断用 `action: hangup`。工具会按用户选定的话机类型执行。仅在用户明确要求拨号或挂断时执行。重名、查不到或没有有效分机号时，把工具返回的提示转告用户，请其提供邮箱或完整分机号。

在「工具箱 → 技能 → 办公电话 → 设置电话」选择话机类型。Cisco 默认使用当前 TP CoWork 登录账号，只拨打 `1121xxxx` 格式的八位办公分机；需要重新认证时引导用户登录 TP CoWork。Yealink 需要在设置中确认自己的四位主叫分机与话机配置，可导入本机的旧版配置。

电话类型和 Yealink 配置保存在本机。Cisco 登录凭证由后端账号服务处理。不要让用户在聊天中发送凭证或通过脚本拨号。返回「已发送指令」表示请求已被接受，是否接通以话机状态为准。拨号结果未知时请用户先查看话机，避免重复拨号。
