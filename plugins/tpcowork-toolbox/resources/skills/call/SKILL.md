使用原生 `call` 工具，action 为 dial 或 hangup；拨号传 number。仅在用户明确要求拨号或挂断时执行，仅接受用户提供的数字号码，不推测联系人。

首次使用：打开“工具箱 → 技能 → call → 设置电话”，填写并确认自己的四位办公分机号。软件从本机分机表匹配话机地址，可复用旧版 `skills/call/config.json` 中同一主叫的配置。没有旧版凭证时，在设置电话页面首次填写话机登录账号和密码；无法匹配地址时，在“话机与分机表设置”中补充。自己的分机号与要拨打的号码是两个不同字段，不得替用户猜测主叫。

配置保存在本机，凭证由 DSH credentials 保存和解析；不要让用户在聊天发送密码，也不要读取、打印或复制个人通讯录和凭证。配置检查和保存不会拨号。返回“已发送指令”不等于对方已接通。不得为连通性测试自动拨号，不得通过脚本或 curl 重拨。
