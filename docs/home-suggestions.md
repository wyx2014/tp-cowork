# 首页任务推荐

工具箱插件在 DSH 原生首页输入框下提供“试试这些任务”。首批为磁盘占用分析、每日新闻简报和演示文稿；每次三条，“换一批”轮换当前面板，其他面板不受影响。使用参考项目 tp-cowork 的文案、图标与列表布局，支持浅色、深色、窄窗口和中英文。

点击推荐替换当前草稿并聚焦原生输入框，不创建已提交任务、不自动发送。演示文稿绑定已安装且可用的 office-pptx，显示“演示文档”；新闻简报绑定 control-browser，Word 和 Excel 分别绑定 office-docx、office-xlsx。引用沿用工具箱能力选择、原生编辑器和任务提交接口，可删除、撤销和再次选择。能力读取期间用户修改草稿、切换会话、点击另一项或关闭推荐时，迟到结果不得覆盖输入。不可用的技能保留普通提示词并显示说明，不自动安装或启用。

关闭推荐先确认，结果保存在本机界面偏好中；可从 DSH 通用设置的“主动任务推荐”重新开启。新建会话不改变该偏好；已有消息的会话不显示推荐。配置和任务执行继续由 DSH 原有服务负责。
